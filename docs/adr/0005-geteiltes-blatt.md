# 0005: Ein geteiltes Blatt für alle drei Spieler

Datum: 2026-10-31 · Status: Angenommen

## Kontext

In Balatro gehört das Deck dem Spieler allein. In Skat spielen alle aus demselben Blatt, und das Mitzählen der Karten ist der Kern des Spiels.

## Entscheidung

Es gibt genau ein Blatt pro Run. Alle Kartenmodifikationen und alle hinzugefügten oder entfernten Karten betreffen alle drei Spieler. Entfernte Karten werden durch Blanko-Karten ersetzt, damit die Verteilung 10/10/10/2 erhalten bleibt.

## Alternativen

- Eigenes Blatt pro Spieler: bricht das Mitzählen und damit Skat.
- Modifikationen wirken nur in der Hand des Spielers: sicherer, aber ohne Spannung. Bleibt als seltene, teure Sonderform erhalten.

## Folgen

Deckbau ist immer ein Risiko. Das UI muss die Wahrscheinlichkeit zeigen, dass eine Karte beim Spieler landet. Das Balancing muss beide Seiten einer Modifikation messen.
