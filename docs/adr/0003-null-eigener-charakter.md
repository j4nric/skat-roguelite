# 0003: Null ist ein eigener Charakter

Datum: 2026-10-31 · Status: Angenommen

## Kontext

Null hat keine Trümpfe, eine andere Rangfolge, ein umgekehrtes Ziel und feste Werte statt Grundwert × Stufen. Als Option neben Farbspiel und Grand wäre es ein Fremdkörper in der Score-Engine.

## Entscheidung

Null wird ein eigener spielbarer Charakter mit eigenem Startblatt, eigenem Shop-Angebot und eigener Wertungsformel. Der Standard-Charakter spielt nur Farbspiel und Grand.

## Alternativen

Null als dritte Spielart im Standard-Run: zwingt Spieler, zwei gegensätzliche Deckbau-Richtungen gleichzeitig zu verfolgen, und macht Balancing unmöglich.

## Folgen

Der Kern muss Spielart und Wertung so trennen, dass ein Charakter beides vorgeben kann. Der Nullspieler wird nach dem Standard-Charakter gebaut (Meilenstein M4).
