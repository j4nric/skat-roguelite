# 0001: ADRs verwenden

Datum: 2026-10-31 · Status: Angenommen

## Kontext

Das Design-Dokument hält den aktuellen Stand fest, aber nicht, warum Entscheidungen gefallen sind. In einigen Monaten weiß sonst niemand mehr, warum es Blanko-Karten gibt.

## Entscheidung

Jede grundlegende Entscheidung bekommt ein ADR in `docs/adr/`. Das Design-Dokument verweist auf ADRs, statt Begründungen zu wiederholen.

## Alternativen

Begründungen im Design-Dokument selbst: wird unübersichtlich und verliert Historie.

## Folgen

Ein wenig Schreibarbeit pro Entscheidung. Dafür ist jede Richtungsänderung nachvollziehbar.
