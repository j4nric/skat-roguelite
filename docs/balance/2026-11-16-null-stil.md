# Null-Stilbonus abgeschwächt (Cockpit q49)

- **Datum**: 16.11.2026
- **Branch**: `feat/null-style-bonus`
- **Agent**: `core-dev`
- **Anlass**: Im Spieltest brachte ein einfaches Null ohne Relikte sehr viele Punkte. Entscheidung des Nutzers (q49): „C: Sofort abschwächen (z. B. Kurzschluss +1 statt +3)“ und besser erklären.
- **Formel** (DESIGN 9.2): Null zählt 23 × (Risikostufe + Stilbonus). Stilbonus nur beim gewonnenen Null: +1 je Stich mit einer unterlaufenen Sieben, +2 nie bedienen müssen, +3 Kurzschluss (die Gegner haben nach fünf Stichen mindestens 61 Augen).
- **Maßstab**: PIMC-Spieler (`--bot pimc:12:3`), mit Tresen, je Charakter 7 × 300 Runs (Seeds 42 bis 48, 2100 Runs; Standardfehler rund 1,1 / 0,8 / 0,4 Punkte für Stadtteil 2 / 3 / gewonnen). Der Simulator zählt seit diesem Branch den Stilbonus der gewonnenen Nullspiele (Zeile `null style (won)`) und je Spielart den Spielwert gewonnener Spiele nach den Regeln allein, ohne Relikte und Faktor (Spalte `rule value`).

## Befehle

```sh
cargo build --release -p skat_sim
./target/release/sim --seed 42 --runs 300 --bot pimc:12:3 --character null   # Seeds 42 bis 48
# dasselbe mit declarer, shirker, tailoress, heart_brother, gambler, ramsch_aunt
```

## 2. Varianten

Kurzschluss +1 (A), dazu höchstens zwei (B) oder eine (C) unterlaufene Sieben, die zählen (neues Feld `max_sevens_ducked` in `NullFormula`). Stadtteil 2 / Stadtteil 3 / gewonnen, dahinter der Spielwert eines gewonnenen Null nach den Regeln.

| Variante | Alleinspieler | Null-Wert | Nullspieler | Null-Wert |
|---|---|---|---|---|
| vorher (Kurzschluss +3, jede Sieben) | 39,7 / 15,2 / 3,5 % | 98,8 | 37,0 / 14,6 / 3,7 % | 98,4 |
| A: Kurzschluss +1 | 38,2 / 15,4 / 3,4 % | 91,5 | 36,4 / 13,4 / 3,0 % | 92,4 |
| **B: Kurzschluss +1, höchstens 2 Siebenen** | **37,4 / 14,7 / 3,0 %** | **79,9** | **32,6 / 11,1 / 2,6 %** | **84,7** |
| C: Kurzschluss +1, höchstens 1 Sieben | 33,9 / 11,7 / 2,6 % | 61,3 | 20,0 / 5,1 / 0,8 % | 68,0 |

- **A allein** nimmt einem gewonnenen Null nur 7 Punkte (98,8 → 91,5): Das Null bleibt beim Zweieinhalbfachen eines Farbspiels. Der Spieltest-Eindruck bliebe.
- **B** senkt den Null-Wert auf 80, das Doppelte eines Farbspiels und ein Drittel über dem Grand, bei deutlich höherem Risiko (58 % gewonnen statt 74 %). Der Bot sagt seltener Null an (Alleinspieler 38,7 % → 34,8 % der Spiele). Der Nullspieler verliert 4,4 / 3,5 / 1,1 Punkte, bleibt aber spielbar (mit festen 23 kam er nur zu 7 % in Abschnitt 2, DESIGN 9.2).
- **C** brächte das Null auf Grand-Niveau, aber der Nullspieler gewönne nur noch 0,8 % der Runs. Ohne neue Zielwerte nicht tragbar.

**Gewählt: B.** Kurzschluss +1, höchstens zwei unterlaufene Siebenen zählen, „nie bedienen“ bleibt +2. Ein Null mit drei Siebenen und Kurzschluss zählt jetzt 23 × 4 = 92 statt 23 × 7 = 161.
